Scrape the road traffic data of Rennes and display them on a Power BI dashboard

The aim of this project is to scrape road traffic data updated every 30 minutes in Rennes and to analyse and display it on a Power BI dashboard. In order to complete this task, I am going to use a script to scrape data, another to clean these data and concatenate them into a single file. Finally, I will store all these data in a PostgreSQL Database. You can find all scripts and the Power BI dashboard on my GitHub repositery here.
